# DoorGo Brand and UI

## Brand
- Product: `DoorGo`
- Descriptor: `Door Shop Operations`
- Possible tagline: `Measure. Build. Schedule.`
- Approved mark: simplified T/SD configuration.
  - navy transom
  - narrow navy sidelight
  - larger blue door
  - very slight corner radius
  - no handle hole
  - crisp geometric construction

## Brand intent
- Modern and software-forward.
- Directly connected to the door industry without becoming a literal open-door illustration.
- Avoid obvious arrows, roads, calendars, tape measures, checkmarks, and generic progress icons.

## Home page
The home page is an internal navigation hub, not a sales page. Use the logo, descriptor, tagline, and short practical area descriptions. Prefer useful status counts over paragraphs.

Approved concise descriptors:
- Measure — `Record site measurements and door details.`
- Jobs — `View and manage active jobs.`
- Work Orders — `Create and print shop instructions.`
- Production — `Track work through the shop.`
- Schedule — `Plan production, deliveries, and pickups.`
- Documents — `View, print, download, and send files.`
- Tools — `Open calculators and shop references.`
- Reports — `Review workload and activity.`
- Settings — `Manage users and app preferences.`

## UI writing
- Use door-shop terminology.
- Prefer one brief instructional line.
- Avoid sales language such as “unlock efficiency,” “transform,” or “streamline success.”
- Avoid unexplained software jargon.
